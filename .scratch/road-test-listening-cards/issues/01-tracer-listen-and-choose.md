# 01 聽一張卡、四揀一、睇回饋（tracer）

Status: done

Spec: `../spec.md`

## 要做咩

打通最薄嘅一條路：打開網頁，聽到一句英文，揀中文答案，見到回饋，再去下一張。

- 起好純 HTML/CSS/JS 骨架（冇 build），手機尺寸優先，介面繁體中文。
- 定好卡片資料格式：英文句子、中文意思、類別、重點詞彙解釋、應該做咩動作、（可選）英文參考答案同中文解釋。
- 先放約 10 張「行車方向指示」卡做種子資料。
- 用 Web Speech API 以 en-GB 讀出英文句子，有重播按鈕。
- 四個中文選項：三個錯選項由同類別其他卡抽，唔可以同正確答案係同一個中文意思。
- 揀完即時顯示：啱錯、英文原文、中文答案、重點詞彙解釋、應該做咩動作；卡有參考答案就一併顯示。
- 「下一張」按鈕，隨機出下一張。
- 整選項嘅邏輯寫成 ES module，同 DOM/TTS 分開，用 `node --test` 測試。
